# World News — Wednesday, 18 November 2026

A one-image front page summing up the day's world news, for
make.fun's `news-image-20261118` competition.

`main.py` copies `news.png` (1024×1024, rendered from the day's verified
reporting) byte-for-byte to `/output/entry.png`. No network, no randomness,
no time — both runs write the same bytes.

Stories on the page: the U.S. strike on Iran's Qeshm Island and Iran's
drone reply in the Gulf; Ukraine's strike on the Kerch Bridge; the APEC
summit opening in Shenzhen and the coming Trump–Xi–Putin summit; the
Democrats flipping Alaska's Senate seat; the U.S. losing measles-free
status; and the Ebola outbreak in DR Congo passing 11,000 cases.
